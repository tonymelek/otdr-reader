Standard OTDR record

What the viewer reads

A SOR file is the Telcordia SR-4731 record from an optical time-domain reflectometer. Version 2 files start with a map of named blocks. This viewer seeks each block from that map.

Blocks

  • General parameters: language, cable and fiber identifiers, locations, operator, comments.
  • Supplier parameters: the instrument, module, and software that wrote the file.
  • Fixed parameters: date, wavelength, pulse width, range, index, and acquisition settings.
  • Key events and the link summary: distance, loss, reflectance.
  • Data points: the trace drawn on the graph.

What stays here

The file is read with the browser file API. Nothing is uploaded. Version 1 records are not supported.
